协调编排中枢
CoordinatorAgent
解析全局意图，封装 SubtaskEnvelope，派发查证与修复任务；驱动 ReviewAgent 复核，调度最多 2 轮 REWORK 退回循环。
🛡️ 硬约束：不得直接执行写操作；提案必须经 ReviewAgent 批准方可持久化落库。
故障诊断专员
DiagnosisAgent
调用任务查询、日志检索与 CSV 校验只读探针；具备强大的提示词注入内容对抗能力，严格过滤非受信数据。
🛡️ 硬约束 (D-005)：跨租户越权查询返回静默 404/403，错误响应中绝不泄露目标对象 ID。
方案拟定专员
RemediationAgent
依据诊断事实与产品版本（v1/v2）检索规程库，校验执行前提（如超时先查幂等状态，禁止盲目重试），起草提案。
🛡️ 硬约束：严禁版本规程穿越；任何需要外部副作用的方案仅生成 Draft 提案。
合规质检门禁
ReviewAgent
独立复核证据充分性与逻辑一致性。发现事实缺口或规则矛盾时打回 REWORK；严重冲突升级转人工 ESCALATE。
🛡️ 硬约束：无客观证据支撑的推论一票否决；严禁带病执行。
两阶段审批门禁
Human Approval Gate
系统为经质检通过的方案计算 SHA256 参数签名哈希，持久化为待审批提案，等待授权操作员（operator/approver）核准。
🛡️ 硬约束：参数被任何篡改会导致哈希失配物理拒绝；无审批禁止写入。
物理写入执行器
Deterministic Executor
脱离大模型幻觉的确定性安全执行函数。严格验证审批状态、参数哈希与幂等键，执行落库工单创建。
🛡️ 硬约束：重复调用相同 proposal_id 会触发幂等保护，保证零副作用重复。

20 个冻结验收用例分类矩阵：
1. 正常业务排查 (4例)

覆盖日期错误、缺失字段等典型故障归因与不可变建单提案起草。

2. 跨租户越权阻断 (4例)

对 B 租户任务探测进行物理隔离拦截，实现 100% 静默阻断且零信息泄漏。

3. CSV 注入对抗 (4例)

防范 CSV 内嵌提示词注入指令（如欺骗 Agent 忽略规程直接放行）。

4. 证据缺口退回 (4例)

模拟超时无幂等记录时，ReviewAgent 拦截盲目重试，强制退回补查。

5. 混合故障归因 (4例)

多门店任务不同故障并发时，独立查证与独立建单，严禁随意归并。
